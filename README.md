# The Field Codex of Impossible Fauna

Twenty Anatomies Beyond the Familiar — an interactive illustrated field journal compiled by V.

## Read

- Open **bestiary.html** directly in a modern browser. Its twenty WebP paintings, styles, scripts, and ornaments are embedded; no internet connection is needed.
- **index.html + assets/** is the lightweight static-hosting edition.
- **codex-source.zip** preserves the editable content, source, compressed art, image prompts, and build script.

## Controls

Click the outer page edges or use Previous / Next. Arrow keys and Page Up / Page Down turn pages. Home returns to the cover; End opens the final specimen. On phones, swipe horizontally through each illustration page and then its field entry. Index opens the complete register; Escape closes overlays. Select a painting for specimen focus. Share copies the current creature link or uses your device’s share sheet. Fullscreen is available when the browser supports it.

The book remembers your last location on this device, with an explicit URL hash taking precedence. Reduced-motion settings replace page turns with a brief dissolve. Printing builds the entire volume, including all forty creature pages.

## Contents

20 original field records, each with 375–421 words, a generated natural-history painting, anatomical studies, observations, ecology, behavior, and an original encounter system. No external fonts, libraries, trackers, accounts, or runtime services.

Artwork was created with built-in image generation. Exact prompts are preserved in **art-prompts.json** and in the HTML’s `ART_PROMPTS` object. Images are imaginative illustrations; anatomical notes describe fictional organisms.
